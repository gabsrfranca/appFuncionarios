⚙️ Configuração inicial

Antes de usar, insira seu Client ID do Google Cloud:

Como obter o Client ID?
  1. Acesse console.cloud.google.com e crie um projeto.
  2. Ative a Google Drive API em "APIs e Serviços".
  3. Em "Credenciais", clique em "Criar credenciais" → "ID do cliente OAuth 2.0".
  4. Selecione Aplicativo da Web. Em "Origens JavaScript autorizadas", adicione null (para arquivo local) ou a URL onde hospedar.
  5. Copie o Client ID gerado e cole acima.
